### 4. Learning Index — "Discovery Clouds"
- User selects their case from a slim circular slider at the top of the Index screen (supports multiple cases)
- User holds down a glowing orange button at the bottom to unlock the Learning Index for that case (spends 1 credit, sends Case Memory / finished complaint to Claude Sonnet 5)
- Claude extracts the strongest, most significant violations, citations, statutes, amendments, and relevant case law and turns them into learning entries
- Each entry displays as a **Discovery Cloud** — a slim, gently drifting/floating element pairing the difficult name attached to that moment (a perpetrator, judge, officer, or other party) directly next to the relevant law/citation/knowledge. Format: **(Trauma/Law)**.
- Tapping a floating cloud expands it into a larger Discovery Cloud view with the full explanation
- Purpose: turning a difficult moment into something the user can actually learn from and retain
