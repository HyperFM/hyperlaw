 Stop Thinking Like a Form Builder  This isn’t supposed to be a questionnaire.  It’s supposed to be an interactive legal argument builder.  When I choose a screen type, I don’t want to answer 10 static questions in order.  I want the builder to behave like an investigator helping me organize evidence.  For example…  I’m watching bodycam footage.  At 7:43 I hear something important.  I pause the video.  Click Create Screen.  Choose Contradiction.  Instead of dumping ten text boxes on me, start a conversation.  What did you just notice?  I answer.  Who said that?  I answer.  What evidence contradicts that?  I answer.  Is there a recording?  Yes.  Is there a report?  Yes.  Does policy say something different?  Yes.  Then keep asking until the contradiction is complete.  The questions should change depending on my answers.  ⸻  I Want Branching Logic  If I answer:  “No report exists.”  Don’t ask questions about reports.  If I answer:  “There is bodycam.”  Ask:  “What timestamp?”  “What exactly happens?”  “Who is speaking?”  “Does it support Plaintiff or Defendant?”  Every answer should unlock more relevant questions.  Not fixed questions.  ⸻  The Builder Should Think  The app should recognize the argument I’m building.  Examples:  If I keep mentioning:  “They already knew…”  Suggest  “This may be an Admission screen.”  If I mention  “Earlier that month…”  Suggest  “This sounds like a Prior Incident.”  If I mention  “The report says…”  “This video says…”  Suggest  “This should be a Contradiction screen.”  Almost like ChatGPT helping organize evidence.  ⸻  Every Screen Should Be Modular  Instead of hardcoding layouts…  Create reusable blocks.  Examples:  Large Headline  Quote Block  Timeline Block  Question Block  Evidence Card  Icon Row  Policy Comparison  Report Comparison  Conclusion Box  Violation Footer  Warning Box  Key Fact Box  Evidence Source  Photo  Video Still  Transcript  Statute  The app assembles these blocks automatically.  ⸻  Stop Making Just Three Templates  I eventually want 50+ screen types.  The architecture needs to support adding new templates easily.  Every template should define:  * Questions * Logic * Components * Layout * Suggested icons * Suggested colors * Suggested evidence blocks  ⸻  Build a Visual Editor Too  After AI generates the screen…  I still want to tweak it.  I should be able to  * drag blocks * resize blocks * change icons * swap colors * move text * add photos * add arrows * add highlights  without rebuilding the whole thing.  Think Canva.  ⸻  AI Should Write Better Than Me  After I answer questions…  Don’t copy my wording.  Rewrite it.  Make it cleaner.  More persuasive.  More professional.  More concise.  More powerful.  Like a trial attorney writing exhibit boards.  ⸻  Build an Entire Project  This isn’t just one screen.  It’s an entire case.  Project  ├── Incident  ├── Screens  ├── Timeline  ├── Evidence  ├── Witnesses  ├── Policies  ├── Statutes  ├── Photos  ├── Videos  ├── Reports  ├── Audio  ├── Court Filings  ├── Counts  ├── Export  Every screen belongs to a case.  ⸻  The Finished Product  This should feel like using Canva mixed with ChatGPT.  I shouldn’t feel like I’m filling out forms.  I should feel like I’m building a case.  The AI should guide me through organizing evidence, recognize patterns, suggest better screen types, rewrite my wording, and automatically generate courtroom-quality presentation boards in the same visual style as my attached examples.
