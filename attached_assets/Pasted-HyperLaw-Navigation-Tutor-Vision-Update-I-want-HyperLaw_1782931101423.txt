HyperLaw Navigation & Tutor Vision Update

I want HyperLaw’s navigation to reflect how people naturally build a case and learn from it.

🏠 Home

The user’s dashboard.

Shows:

* Continue recent case
* Recent projects
* Recent exports
* AI suggestions
* Quick actions
* Case progress

This is where users always return.

⸻

🛠 Build (Center Tab)

This is the heart of HyperLaw.

Everything is created here.

Users can:

* Build legal screens
* Create documents
* Organize evidence
* Manage projects
* Build timelines
* Create visual exhibits
* Edit and arrange presentation slides

As users work, HyperLaw automatically understands the facts being entered.

No additional setup should be required.

⸻

🎓 Tutor

Tutor should automatically learn from whatever the user is currently building.

Instead of asking the user to start over or explain everything again, Tutor should use the facts already contained in the active project.

For example:

If the user builds a screen discussing an officer’s actions, Tutor immediately recognizes the legal concepts that may be relevant and begins teaching from those facts.

Tutor should explain:

* Why certain facts matter
* Which evidence strengthens an argument
* Which facts weaken it
* What additional evidence may be useful
* Questions the user should consider next

Tutor should never simply label legal violations.

Its purpose is to teach legal reasoning using the user’s own evidence.

⸻

🧠 Learning Mode

Tutor should also include an optional learning mode.

Users can study their own case using interactive learning cards.

Examples include:

* Fact Cards
* Legal Concept Cards
* Evidence Cards
* Question Cards
* “Why does this matter?” cards
* “What would strengthen this?” cards

These should feel like modern study cards rather than traditional flashcards.

The goal is to help users genuinely remember legal concepts by connecting them directly to their own case.

⸻

👤 Profile

Contains:

* Account
* Subscription
* Settings
* Theme
* Saved Preferences
* Export History
* Case Backups
* AI Preferences

⸻

Remaining Navigation Tabs

I have not finalized the remaining one or two tabs yet.

For now, please design the navigation so additional modules can be added later without requiring another redesign.

The overall navigation should be modular and expandable as HyperLaw grows.
